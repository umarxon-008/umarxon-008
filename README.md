# NeuraMed

Bemor, shifokor va dorixonani bogʻlaydigan yagona tibbiy platforma (hakaton demo).

| Papka | Nima |
|---|---|
| [`NeuraMed/`](NeuraMed) | **Asosiy loyiha.** Next.js 14 + API + Prisma. Ikki rol: bemor va shifokor. Boʻlimlar: Salomatligim (karta, chekap), dorilar, tahlillar, MEDAI, PHARMA TRACE, MEDCONNECT. Oʻzbek, qozoq, qirgʻiz, tojik, rus va ingliz tillari. |
| [`MEDPERFECT/`](MEDPERFECT) | Arxiv: birlashtirishdan oldingi HTML/JS versiya va PowerPoint taqdimoti. |

## Tez boshlash

```bash
cd NeuraMed
npm install
npm run dev     # http://localhost:3000
```
